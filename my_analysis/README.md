# H -> ZZ* -> 4l evaluation submission (task h4l_ntuple, EVAL_CONTRACT v0.4)

    ./run.sh <dataset_dir> <output_dir>

writes `RESULT.json` and `MODEL.json` (the fitted binned likelihood as a pyhf workspace at the fitted m_H, buildable with
`pyhf.Workspace(spec).model()`), plus `MODEL_meta.json`, `summary.txt`, `results_full.json` and `logs/run.log`.
The environment is `pixi.toml` / `pixi.lock` (ROOT for the large input files, numpy/scipy/iminuit/uproot); `run.sh`
uses an already active environment with ROOT and those packages, else `pixi run --frozen`.  `EVAL_CONTRACT.md` is the
contract with the per-flavour calibration block used here.

Method (the main analysis of this repository, `analysis_v3/`, with equivalent faster implementations; AN in
`deliverables/AN_h4l_ul16_pfnano_v2/`):
1. `src/h4l_reader.cpp` (ROOT, compiled at run time, parallel over file chunks): AN-16-442 loose leptons with FSR
   photons and FSR-subtracted isolation, the Z -> ll calibration pairs, tag-and-probe pairs, loose-lepton event records.
2. Lepton calibration per flavour on Z -> ll (`h4l_eval/calibration.py`): the main analysis's factorized scale/smear
   model, category families, response pass, joint least squares and iteration (histogram-convolution templates).
3. Tag-and-probe SF of the full single-lepton selection (`h4l_eval/tnp.py`; simplified: calibrated MC template,
   CMSShape background, exponential alternative).
4. Final selection (`h4l_eval/selection.py`): AN tight leptons, ZZ candidates, smart cut, Z1 kinematic refit, per-event
   mass uncertainty (candidate choice: Z1 closest to m_Z, then the largest Z2 scalar pT sum; no MELA available).
5. Z+X by the OS method with fake rates from Z + 1 lepton (`h4l_eval/zx.py`), shapes and the closure systematic of the
   main analysis (`h4l_eval/data/constants.json`, generated by `analysis_v3/eval/make_eval_constants.py`).
6. Binned likelihood m4l (105-140 GeV, 0.5 GeV) x 3 D_mass bins x 3 final states (`h4l_eval/model.py`), mu and m_H
   floating (m_H in [110, 140] GeV), nuisances: lepton scale/resolution (histosys), efficiencies and Z+X (normsys);
   MINOS intervals, stat with the nuisances fixed, syst from the impacts, toys for the GoF p-value and the coverage.

Calibration in RESULT.json: per flavour under the registered names (`scale_shift`, `smear`, `sel_eff`, each
`{"muon": {value, unc}, "electron": {value, unc}}`), the data-weighted averages over the Z -> ll calibration-sample
leptons.  A ~10 fb^-1 dataset runs in about 18 minutes on 16 cores (EOS FUSE input).
